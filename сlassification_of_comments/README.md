### Проект по поиску токсичных комментариев для отправки на модерацию, классификация
- `Python 3` `Jupyter Notebook`
- `pandas`, `nltk`, `torch`, `transformers`, `catboost`, `scikit-learn`
- Данные предоставлены Яндекс Практикумом, включают размеченные комментарии (text — текст комментария, toxic — целевой признак)
- Для поиска лучшей модели использовали 3 подхода:
- 1 подход: класическая векторизация с предварительной очисткой и лемматизацией + классическая классификация (обучили: TF-IDF+LogisticRegression и CatBoostClassifier)
- 2 подход: предобученная модель для векторизации и классическая классификация (обучили: эмбединги BERT+LogisticRegression)
- 3 подход: предобученная end-to-end модель (roberta_toxicity_classifier)
- Модели обучены на кросс-валидации с подбором гиперпараметров, практически все удовлетворяют заданной метрике
- Лучшая модель (roberta_toxicity_classifier) на тестовой выборке далеко превзошла требуемый порог 
- Проведен анализ лучшей модели, сделаны выводы и рекомендации
- `Бизнес-результат`: с помощью прогнозов модели автоматизируется поиск токсичных комментариев с целью отправки их на модерацию
