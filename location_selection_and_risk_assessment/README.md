### Проект по выбору локации для скважины, регрессия с оценкой прибыли и модельных рисков (техника Bootstrap)
- `Python 3` `Jupyter Notebook`
- `pandas`, `matplotlib`, `seaborn`, `numpy`, `scipy`, `phik`, `scikit-learn`
- Данные предоставлены Яндекс Практикумом и состоят из нескольких файлов (данные по регионам)
- Данные были предобработаны, проведен исследовательский и корреляционный анализ с визуализацией результатов
- Для каждого региона выбраны по 200 лучших скважин по прогнозу запаса сырья
- Проведен расчет возможной прибыли и рисков с применением техники Bootstrap для каждого региона
- `Бизнес-результат`: на основе анализа выбран наиболее перспективный регион для разработки
